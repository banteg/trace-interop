# Besu: changes to review

Start with failed-frame reporting, precompile output and inclusion, and range-filter consistency. Individual replay also needs a scope decision. 26.10.0 · 976ca7ea and 26.10.1 · e83703cd, which only unschedules Amsterdam on Hoodi, ship what the October 11 development build carried: it runs unsigned calls like eth_call (#11404), returns rejected trace_callMany bundles as one JSON-RPC error (#11401), starts each trace_callMany call at a transaction boundary (#11365), reports each rejected item with its own reason (#11432) and selects exactly the hashed block in trace_filter (#11407). It and the development build also return null for an unknown transaction hash (#11379) and Block not found for an unknown block (#11381). 26.10.2 · d3e1aea7 added the trace_filter mode member (#11436, H03) and the omitted trace_callMany block (#11440, H31); 26.11.0 · 0e595f9e shipped the same trace changes and agreed on 8 decisions. 26.11.2 · 09b9e94d adds trace_replayTransaction (#11406, H01), so the replay cases of H07, H08, H18 and H19 run and agree, rejects malformed trace_filter members and legacy calls for another chain (#11439), resolves safe and finalized trace_filter bounds while rejecting pending (#11441, H32), keeps failures local to their frame (#11345, H24), retains precompile output (#11346, H22) and nonzero-value precompile frames (#11360), reports empty code for self-destructing creations (#11362, H26) and creationMethod on every create frame (#11435, H10). It agrees on 19 decisions. It ignores trailing trace_call parameters, so positional state and block overrides run on unmodified state (H15) and an account override with both state and stateDiff is accepted (H14). 26.11-develop · f58f40e2 rejects those parameters and also retains root precompile halt reasons (#11347): it agrees on 20 decisions.
