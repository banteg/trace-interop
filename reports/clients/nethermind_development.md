# Nethermind: changes to review

2.2.0 · 1d2aff00 agrees on filter modes and empty address lists (#13857), post-merge and genesis reward records (#13938, #13783, #13801), vmTrace steps (#13940, #13958), precheck and collision frames (#13957), failed-frame results and labels (#13981) and null for a missing transaction or replay (#13937, #14037). It also validates trace_rawTransaction as block inclusion does (#14091), rejects disagreeing data and input (#14089), rejects block-hash filter bounds and selects one block with the trace_filter blockHash member (#14111), runs blob calls without a positive blob fee cap at BLOBBASEFEE 0 (#14092) and answers rejected calls with the eth_simulateV1 codes (#14158). Its one remaining difference is H14: its release branch was cut before #14212 and #14663, so an explicit type still adds requirements, fields a call’s fork lacks run, and a lone maxFeePerBlobGas is ignored. 2.2.0-preview · 159862be includes both and agreed on all 33 decisions until the draft pinned forms it had left open for exact fixtures (5e6717fe): halted frames, rewards and SELFDESTRUCT records need result null (H09), rewards null transaction fields (H05), vmTrace operations op (H21) and an unknown block -32001 (H06); a code sender’s rejection message, gas-defaulting probes its funds cannot cover and the legacy-priced authorization list remain unassessed or open.
