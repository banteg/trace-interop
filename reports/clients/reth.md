# Reth: changes to review

Reth 2.9.0 · c9a780f4 replaced revm and revm-inspectors with evm2 (#25002), whose Parity tracer carries ports of the revm-inspectors fixes. 2.10.1 · 58ebce14 and the nightly 2.10.1 · 5efe80f5 agree on 25 decisions, as 2.9.0 and 2.8.1 · d763342f did, but not the same 25 as 2.8.1: evm2 reports the post-Cancun SELFDESTRUCT payload, so account deletion agrees (H26) without revm #3833, while vmTrace CALL and CREATE steps lost the forwarded gas from `cost` (H20). The nightly takes evm2 past #744, so its CALL costs include the forwarded gas again; a CREATE still leaves it out, which evm2 #876 fixes. Reth 2.8.0 · 05ba4812, with revm-inspectors 0.44.1 (#27668), had added the reverted-CREATE results, failure labels and vmTrace fixes (H09, H20) to what 2.7.0 shipped: tree-path lookup, default filter intersection, missing-replay nulls, replay transaction hashes, the genesis reward, omitted filter bounds, the omitted trace_callMany block, new-account stateDiff markers, EIP-7702 code changes and executing initcode in vmTrace. Remaining work includes simulation fees, the evm2 vmTrace CREATE cost, and null filter address lists (Alloy #4257, merged but not in an Alloy release that Reth takes).
