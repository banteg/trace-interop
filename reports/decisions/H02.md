# trace_get selector and return shape

H02 · Spec decision · [All decisions](../README.md#decisions-to-review)

**Status: ⚪ Under review** · [Status definitions](../../decisions/README.md#status-key)

No policy conclusion has been recorded. Implementation observations below do not establish client-team agreement.

## Recommendation

Treat the argument as one traceAddress path: [] is root, ["0x0"] first child, ["0x6","0x0"] a nested child. Return one trace object or null for a missing transaction/path. Convert output traceAddress integers to minimal hex quantities; integer request entries return -32602.

The lookup argument should identify the same path that traceAddress describes, with a singular result matching the method name.
