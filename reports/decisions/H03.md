# Filter composition and mode

H03 · Spec decision · [All decisions](../README.md#decisions-to-review)

## Recommendation

Use OR within each address list and AND between fromAddress and toAddress. One unconstrained side should not suppress matches. The portable baseline rejects the mode extension with -32602; optional extension semantics require separate agreement.

Supplying a second filter normally narrows a search; combining two sets of alternatives should be explicit.
