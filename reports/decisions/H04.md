# Empty address lists

H04 · Spec decision · [All decisions](../README.md#decisions-to-review)

## Recommendation

Treat an omitted list or [] as no restriction. If null is accepted, give it the same meaning; document whether null is accepted at all. A supplied nonempty list restricts that side.

Programmatically adding an empty optional filter should not erase all results.
