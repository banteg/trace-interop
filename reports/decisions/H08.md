# H08 — Empty output and unrequested components

**Disposition:** Spec decision / likely reporting fix. Proposal, awaiting client review.

## Proposed behavior

Keep a stable envelope: output is the execution return bytes ("0x" when empty); trace is [] when not requested; stateDiff and vmTrace are null when not requested. Requesting a different tracer must not change or erase the returned execution output.

## Rationale

Empty bytes and an unavailable value are different, and selecting an auxiliary view should not change the primary call result.

## Open questions

Preserve the execution return bytes independently of which optional trace components are requested.
