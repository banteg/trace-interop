# H10 — Creation result field names

**Disposition:** Spec decision / likely schema fix. Proposal, awaiting client review.

## Proposed behavior

Use result.address, result.code and result.gasUsed for successful creation. result.code is deployed runtime bytecode, including "0x" for an empty deployment. Use result.output for CALL results; vmTrace.code for executing initcode.

## Rationale

Creation has two different bytecodes—initcode and deployed code—and their field meanings should remain distinct.

## Open questions

Specify creationMethod if it is required; retain the successful mixed-creation probe and investigate historical-method metadata separately.
