# H11 — Empty trace-type selection

**Disposition:** Likely client bug. Proposal, awaiting client review.

## Proposed behavior

Accept an empty selection, execute the call and return its output with empty/unrequested components. Never leak a collection-reduction exception.

## Rationale

An empty list of auxiliary views is a natural request for just the execution output, and already works identically in three clients.

## Open questions

A focused Nethermind fix and regression fixture can proceed independently of the broader API design.
