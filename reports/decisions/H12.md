## Recommendation

Standardize the two-argument baseline with latest state. Observe an explicitly supplied third block selector as an extension, without marking its acceptance or rejection as baseline conformance. An accepted request alone does not prove that the selected state was used. Agree extension semantics and unsupported-argument errors separately.

The baseline should be usable on all four today without silently changing which state is traced.
