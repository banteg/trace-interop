# Signed transaction nonce validation

H13 · Admission policy proposal · [All decisions](../README.md#decisions-to-review)

[Rule in the pinned draft](https://github.com/banteg/execution-apis/blob/f26e2468b3e5409e777deb137254c2954ce70bc7/docs-api/docs/trace-profile.md#open-details-requiring-focused-review)

## Recommendation

For trace_rawTransaction, honor the signed transaction’s nonce and validity rules at the selected state. Reject nonce mismatch with a stable transaction-validation error. Use unsigned trace_call for hypothetical execution that deliberately relaxes admission rules.

A signed transaction is a concrete transaction, so tracing should not silently rewrite its nonce or return a partial-looking success.
