# Unsigned simulation fees and block environment

H15 · Spec decision / likely environment bug · [All decisions](../README.md#decisions-to-review)

## Recommendation

Allow explicit zero-fee unsigned simulations without changing the selected block’s BASEFEE or other block fields. With nonzero supplied fees, use those fees consistently in opcode context and simulated accounting. Apply the same policy to trace_call and trace_callMany; keep strict signed validation separate.

Relaxing transaction admission for a hypothetical call should not silently rewrite the block the caller selected.
