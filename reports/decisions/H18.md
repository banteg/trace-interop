# H18 — EIP-7702 code changes in stateDiff

**Disposition:** Likely client bug. Proposal, awaiting client review.

## Proposed behavior

Report every actual delegation-code transition, including set, replace and clear, independently of account-creation flags. Preserve authorization changes when later execution reverts, according to execution semantics.

## Rationale

stateDiff must include code that changed, even if the account already existed.

## Open questions

Fix account code-change reporting separately; these cases persist after the VM-delta fix.
