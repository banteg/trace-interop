# vmTrace step timing and deltas

H20 · Implementation alignment / release retest · [All decisions](../README.md#decisions-to-review)

## Recommendation

Define ex.used as post-operation gas remaining, and mem/store/push as effects of that same operation. Use null for no memory write, with actual offset and bytes for a write. Specify call/return gas boundaries using dedicated nested-call fixtures before choosing detailed gas formulas.

A consumer applying deltas in order should reconstruct the state after every opcode without shifting effects to neighboring steps.
