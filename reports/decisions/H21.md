# vmTrace numeric and optional metadata encoding

H21 · Spec decision · [All decisions](../README.md#decisions-to-review)

**Status: ⚪ Under review** · [Status definitions](../../decisions/README.md#status-key)

No policy conclusion has been recorded. Implementation observations below do not establish client-team agreement.

## Recommendation

Encode stack words as minimal hex quantities (zero is 0x0), memory/code as even-length byte strings. Make op/idx optional metadata; require consumers to accept their absence and validate consistency when present. Keep required execution fields independent of these annotations. Keep pc, cost, used and traceAddress as JSON integers. Validate idx only against an explicitly defined numbering convention.

Numeric values and byte arrays have different formatting needs; optional convenience labels should not determine whether a trace can be consumed.

## Background

Parity's [VM operation type](https://github.com/openethereum/parity-ethereum/blob/55c90d4016505317034e3e98f699af07f5404b63/rpc/src/v1/types/trace.rs#L43-L124) serializes pushed stack items as `U256` quantities, but code and memory deltas as byte data. Its original operation record has `pc`, `cost`, `ex` and `sub`; it does not require mnemonic `op` or sequence `idx` fields. [EIP-1474's encoding rules](https://eips.ethereum.org/EIPS/eip-1474#value-encoding) distinguish minimal `Quantity` values such as `0x0` from even-length `Data` bytes such as `0x00`, which explains the recommendation's different encodings.

The pinned [Nethermind VM serializer](https://github.com/NethermindEth/nethermind/blob/a404c4f06a67aee52cc448216b8d37a77062f106/src/Nethermind/Nethermind.Blockchain/Tracing/ParityStyle/ParityVmOperationTraceConverter.cs#L40-L67) serializes its stored `Push` items directly; the linked cases show padded words. Adding `op` or `idx` can help tools display a trace, but the original Parity record did not need them to reproduce execution. Their presence should therefore be checked for consistency without making older traces invalid.
